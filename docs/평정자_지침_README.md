# 인간 재독(human re-read) 평정 안내 — 무엇을, 어떻게 (60명 × 3코더)

## 1. 왜 하나
합성 인물마다 1인칭 한국어 자기소개 글이 있고, 그 글엔 네 특성(재정취약성·디지털활용·권위순응·사회적고립)이 1~5 값으로 미리 들어가 있습니다. 지금까지는 "AI가 쓴 글을 AI가 다시 읽어 맞히는지"만 봤는데, 국제 학술지 심사위원 4명이 공통으로 **"사람이 직접 읽어도 그 값이 나오는지"**를 요구했습니다. 그 인간 검증이 *Scientific Data* 게재의 핵심 관문입니다.

## 2. 받는 파일
- **`human_reread_subset60_coder1.xlsx` / `_coder2.xlsx` / `_coder3.xlsx`** — 코더 3명이 각자 1장씩 채울 **빈 채점표**. 셋 다 같은 인물 **60명**(연령대×성별 10칸에 6명씩, **진짜 인구통계로 층화**), 코더마다 인물 순서를 독립 셔플(순서·교차참조 효과 최소화).
  - 탭 둘: **`지침`**(읽는 법) + **`rater`**(채점표). B열=자기소개 글, C~F열=빈 점수칸.
  - 글 속 답 노출 표기(`(재정 취약성 2)` 등) 제거(leak-strip).
- **`human_reread_key.csv`** — 정답. **평정자에게 주지 말고 공개 저장소에 올리지 마세요**(이미 git 제외).

## 3. 평정자(3명)가 할 일
1. 코더마다 자기 파일 1개만 받습니다.
2. `rater` 탭에서 각 인물의 **B열 글만 읽고** C~F열에 **1~5점**:
   - **재정취약성** 1=매우 안정 … 5=수입 없음/생계 곤란
   - **디지털활용** 1=거의 못 다룸 … 5=능숙
   - **권위순응** 1=비판적/납득해야 따름 … 5=무조건 순응
   - **사회적고립** 1=교류 활발 … 5=완전히 고립
3. **서로 상의 금지(독립)**, 정답 안 봄, 빈칸 없이.
4. 다 채우면 `human_reread_subset60_coder1_FILLED.xlsx` 식으로 저장해 담당자에게 전달.

※ 한국어 가능 평정자 3명. 1인당 약 45분~1시간(60명).

## 4. 담당자(Daniel) 채점
세 FILLED 파일이 모이면:
```
py score_human_reread.py \
   --sheets results/human_reread_subset60_coder1_FILLED.xlsx \
            results/human_reread_subset60_coder2_FILLED.xlsx \
            results/human_reread_subset60_coder3_FILLED.xlsx \
   --key results/human_reread_key.csv --out results
```
→ 속성별: **Krippendorff α + 평균 QWK**(평정자 간), **recovery QWK(합의값 vs 원래값) + 95% 부트스트랩 CI + Spearman**. α<0.667은 자동 플래그.
→ `human_reread_results.csv`만 Claude에게 주면 §4.2 반영.

## 5. 논문 방법에 *반드시* 정직하게 적을 두 줄
1. **부분표본**: 전수 2,000이 아닌 **층화 60명**(연령대×성별)에 대한 검증임.
2. **저자 1인 포함**: 코더 3명 중 1명이 저자이면 그렇게 명시(가능하면 coder2·3은 구성 모르는 독립인).

## 6. 해석 + 보험
- recovery QWK ≈ 0.7+ → 글이 값을 담고 있음(AI끼리만 검증하던 한계 해소).
- 특정 속성(특히 **디지털활용**) recovery QWK가 0.7 근처이고 CI 하한이 0.6 밑이면 심사위원이 "약하다"고 봄 → 그 속성만 코더 추가 또는 n을 100으로 늘리는 게 보험.
