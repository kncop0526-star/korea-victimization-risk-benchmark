# Data Card / 데이터 카드

Following the *Datasheets for Datasets* format (Gebru et al., 2021).

## Motivation

- **Purpose.** Provide reproducible, PII-free synthetic cohorts for crime-prevention research,
  agent-based simulation, and police-officer training in the Korean context.
- **Created by.** [YOUR NAME], [YOUR AFFILIATION]. Derived from NVIDIA Nemotron-Personas-Korea.
- **Funding.** [state any funding, or "none"].

## Composition

- **Instances.** Synthetic Korean personas (derived subsets of the 1M-row upstream dataset).
- **Fields.** 12 demographic + 6 long-form persona + 8 free-text columns (see upstream schema).
- **Real people?** No. Fully synthetic; no PII.
- **Sensitive content.** Cohorts reference age, household type, education, occupation — used for
  *protection* targeting only (see ETHICS.md).
- **Coverage gaps.** Ages 19–99 only (no minors); single country (대한민국).

## Collection process

- Personas generated by NVIDIA via NeMo Data Designer (not collected from individuals).
- This repository performs **filtering and validation only**; it does not alter persona content.

## Preprocessing / cleaning / labeling

- Cohort selection via abstracted predicates (`config/`).
- Validation against KOSIS census microdata (χ² goodness-of-fit).
- No re-labeling of individual personas.

## Uses

- **Intended.** Prevention research, simulation, education, officer training.
- **Out of scope / prohibited.** Targeting real individuals; offender profiling; representing
  synthetic personas as real victims. See ETHICS.md §4.
